# Status Page Guide

Our public status page is generated from the incident feed. Operators should
follow the runbook below when declaring an incident.

## Declaring an incident

1. Open the incident in the on-call tracker.
2. Post the first customer-facing update within fifteen minutes.
3. Update the status page whenever the impact changes.

## Resolving an incident

Publish the resolution summary before closing the incident. Attach the post-mortem
link once the review is scheduled.
